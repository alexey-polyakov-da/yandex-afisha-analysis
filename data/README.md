# Данные проекта

В проекте использованы обезличенные данные о бронированиях билетов сервиса «Яндекс Афиша» за период с июня по октябрь 2024 года.

## Состав данных

### `final_tickets_orders_df.csv`

Данные о заказах билетов: 290 849 строк и 14 столбцов.

Основные поля:

- `order_id` — идентификатор заказа;
- `user_id` — идентификатор пользователя;
- `created_dt_msk` — дата заказа;
- `event_id` — идентификатор мероприятия;
- `device_type_canonical` — тип устройства;
- `currency_code` — валюта оплаты;
- `revenue` — выручка;
- `tickets_count` — количество билетов;
- `service_name` — билетный партнёр;
- `days_since_prev` — количество дней с предыдущей покупки.

### `final_tickets_events_df.csv`

Справочник мероприятий: 22 427 строк и 11 столбцов.

Содержит названия и типы мероприятий, организаторов, регионы, города и площадки.

### `final_tickets_tenge_df.csv`

Курс казахстанского тенге к российскому рублю за 2024 год: 357 строк и 4 столбца.

Используется для пересчёта выручки в единую валюту.

## Доступ к данным

Исходные CSV-файлы не публикуются в репозитории. Репозиторий содержит подготовленный ноутбук с кодом, сохранёнными результатами расчётов, графиками и выводами исследования.

Для запуска проекта со своими данными необходимо поместить файлы в папку `data` с указанными выше именами.
